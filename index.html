4 · ASCII

6 · Sound
Water noise follows mean flow speed, the drone follows the current hydrograph value, droplets follow turbulence.
7 · Output & export
Standalone web player: a full-screen .html of the current scene (no sidebar), with data, colours, type and zoom built in. Host it on GitHub Pages or embed it with an <iframe>.
Only embed the brand font if its licence allows web use; otherwise the player falls back to the system sans.
Video records WebM (Chrome/Edge/Firefox) or MP4 (Safari) with sound if on — plays in any modern browser via <video>. For 8K, export stills; record motion at 4K or below.
